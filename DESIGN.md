## Brand & Style

This design system establishes an authoritative, crystal-clear B2B knowledge environment tailored for Uzbek enterprise decision-makers, architects, and business leaders navigating corporate software selection (ERP, CRM, WMS, POS, HRM).

### Personality & Demeanor
- **Architectural & Rigorous:** Structured data presented with zero visual ambiguity; communicates institutional reliability and deep technical competence.
- **Modern & High-Performance:** Inspired by high-tier modern enterprise SaaS platforms (e.g., Stripe, Linear, Datadog), prioritizing information velocity, scanability, and effortless navigation.
- **Culturally Grounded & Localized:** Optimized specifically for Uzbek business vocabulary, accounting for Latin orthographic specifics (such as single right quotation marks for letters `o‘` and `g‘`, uppercase title casing, and compound enterprise terminology).

### Visual Movement
A balanced synthesis of **Modern B2B Corporate** and **Tonal Minimalism**:
- Pure background layers layered with subtle slate surface dividers.
- Purposeful color usage where tinting signifies taxonomy (system categories, integration readiness, localized Uzbek tax compliance support).
- Precise geometric balance with generous interactive hit areas and tight typography tracking.

## Colors

The palette delivers unambiguous visual hierarchy, immediate status legibility, and full WCAG AA contrast compliance across all interactive surfaces.

### Core Palettes
- **Primary (`#2F4BFF`):** Vibrant enterprise cobalt. Serves as the primary focal point for global navigation, core actions (CTAs), search highlights, and system classification tags.
- **Secondary (`#1E3A8A`):** Deep navy. Applied to deep navigation headers, primary headline typography, enterprise verification badges, and comparison headers.
- **Tertiary / Success (`#10B981`):** Vivid emerald green. Denotes verified Uzbek localizations, API active status, 1C/E-imzo integration compatibility, and positive audit indicators.
- **Warning / Staging (`#F59E0B`):** Warm amber. Flags legacy architectures, beta software reviews, pending module certifications, or partial localization.
- **Danger / Critical (`#EF4444`):** High-visibility crimson. Signifies deprecated enterprise systems, unsupported protocols, or critical architectural mismatches.

### Neutral Scale (Slate Foundation)
- `slate-950` (`#0F172A`): Primary text, commanding table headers, and deep contrast elements.
- `slate-800` (`#1E293B`): Secondary body text, active icon fills, and panel backgrounds.
- `slate-700` (`#334155`): Secondary body typography, meta descriptions, and table subheads.
- `slate-500` (`#64748B`): Tertiary labels, timestamps, disabled indicators, and breadcrumb dividers.
- `slate-400` (`#94A3B8`): Placeholder values, keyboard shortcut key caps, and inactive border treatments.
- `slate-200` (`#E2E8F0`): Structural containment borders, table grid lines, and interactive dividers.
- `slate-100` (`#F1F5F9`): Soft card backgrounds, table alternating row stripes, and input default fills.
- `slate-50` (`#F8FAFC`): Canvas foundation, secondary sidebar background, and hover states.
- `white` (`#FFFFFF`): High-elevation cards, modals, flyout menus, and active input wells.

## Typography

The dual-type strategy pairs the assertive, contemporary geometry of **Plus Jakarta Sans** for prominent discovery levels with the battle-tested, hyper-legible neutrality of **Inter** for dense catalog matrices, comparison specs, and continuous reading.

### Design Rules
- **Negative Heading Tracking:** All headings `headline-sm` and above require negative tracking (`-0.01em` down to `-0.03em`) to impart an editorial, polished SaaS personality.
- **Body Hierarchy:** Main system reviews, architectural deep dives, and glossary definitions render strictly at `body-base` (16px) with an unhurried 24px line height to minimize reading fatigue in lengthy technical entries.
- **Typographic Character Protection:** Ensure the single right modifier letter (`’` / `ʻ` U+02BB or standard U+2019) used throughout Uzbek terms (e.g., *Taʼminot*, *Lugʻat*, *Qoʻllanma*) matches the main text weight perfectly without vertical shearing.

## Layout & Spacing

The layout model is governed by an unwavering **8px baseline rhythm** (`0.5rem = 8px`, `1rem = 16px`, `1.5rem = 24px`, etc.), creating mathematical predictability across modules.

### Grid Framework
- **Canvas System:** A 12-column responsive fluid layout capped at a maximum content width of `1360px` (`85rem`), centering large-screen views while preventing excessive line lengths in wide text containers.
- **Breakpoints:**
  - **Mobile (< 768px):** 4-column layout, `gutter-mobile` (16px), `margin-mobile` (16px). System catalog filters shift to a swipeable drawer modal.
  - **Tablet (768px – 1024px):** 8-column layout, `gutter` (24px), `margin-tablet` (32px). Secondary sidebar collapses into an icon-rail.
  - **Desktop (≥ 1025px):** 12-column layout, `gutter-desktop` (32px), `margin-desktop` (48px). Tri-pane layouts (Filters / Software List / Quick Spec Sheet) occupy 3 / 6 / 3 columns respectively.

## Elevation & Depth

Visual separation relies on layered surface hierarchy rather than heavy theatrical drop shadows, projecting modern corporate restraint.

### Surface Tiers
- **Tier 0 (Canvas):** `#F8FAFC`. The foundational canvas behind all content groups.
- **Tier 1 (Surface Default):** `#FFFFFF`. Resting card surfaces, navigation headers, step wizard trays, and data tables. Outlined by a razor-thin border (`1px solid #E2E8F0`).
- **Tier 2 (Surface Elevated):** `#FFFFFF` paired with an ambient shadow (`box-shadow: 0 4px 20px -2px rgba(15, 23, 42, 0.06), 0 2px 6px -1px rgba(15, 23, 42, 0.04)`). Used for hovered software cards, active search command popovers, and sticky comparison sticky headers.
- **Tier 3 (Overlay / Popover):** Dropdown menus, keyboard combo pickers (`Cmd+K`), context flyouts, and modal dialogues (`box-shadow: 0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 10px 10px -5px rgba(15, 23, 42, 0.04)`).

### Ghost Borders & Focus Rings
Every interactive element utilizes subtle 1px framing in `#E2E8F0` to maintain crisp shape definition on high-density displays. All active focus states use a sharp dual-ring: `0 0 0 2px #FFFFFF, 0 0 0 4px #2F4BFF`.

## Shapes

The geometric framework balances approachable softness with corporate structure through precise corner radius tiers.

### Radius System
- **`rounded-full` (Pills):** System taxonomy tags (`ERP`, `CRM`, `SCM`), status indicators, shortcut keys, and circular avatar indicators.
- **`rounded-2xl` (16px):** Primary software profile cards, feature highlight modules, comparison matrix tables, and central modal dialogs.
- **`rounded-xl` (12px):** Form text inputs, filter dropdown buttons, interactive accordion rows, and command palette wells.
- **`rounded-lg` (8px):** Internal nested items within cards, action icons, tooltips, and table cell tags.
- **`rounded-sm` (4px):** Individual keyboard key indicators (`Kbd`), checkboxes, and radio buttons.
